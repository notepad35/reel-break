Opens Instagram Reels while Codex or Claude Code works and closes the tab when it finishes.

Requires macOS and Google Chrome.

Codex:
```sh
codex plugin marketplace add notepad35/reel-break && codex plugin add reel-break@reel-break
```
Review and trust the hooks with `/hooks`, then start a new session.

Claude Code:
```sh
claude plugin marketplace add notepad35/reel-break && claude plugin install reel-break@reel-break
```
Start a new session. Allow Chrome automation if macOS asks.
